# Типовой сайт спортивной школы / секции

Основа: структура сайта образовательной организации (проект `orgmu-site`),
спроецированная на спортивную школу. Спортивные школы с 01.01.2023 —
организации дополнительного образования (ФЗ-127 от 30.04.2021), поэтому на
них распространяются ФЗ-273 ст. 29 и приказ Рособрнадзора № 831 о структуре
официального сайта.

Два режима сайта:
- **Лицензированная организация** (ДЮСШ, СШ, СШОР, частная школа с лицензией):
  обязательный блок «Сведения об образовательной организации» включён.
- **Секция без лицензии** (ИП, клуб): обязательный блок выключен, остаётся
  маркетинговая часть + документы по ПДн и оферта.

Терминология: вуз → спортшкола.

| ОрГМУ | Спортшкола |
|---|---|
| Образовательная программа | Программа: дополнительная образовательная программа спортивной подготовки (ДОПСП) по виду спорта или дополнительная общеразвивающая программа |
| Уровень (бакалавриат…) | Этап: начальная подготовка, учебно-тренировочный, совершенствование спортивного мастерства, высшее спортивное мастерство; для общеразвивающих — ознакомительный / базовый |
| Факультет / кафедра | Отделение по виду спорта |
| Преподаватель | Тренер-преподаватель |
| Корпус | Спортивный объект (зал, бассейн, стадион, каток) |
| Группа | Учебно-тренировочная группа (программа + этап + тренер + объект + расписание) |
| Поступающим / абитуриент | Поступающим: приём и индивидуальный отбор |
| Обучающимся | Обучающимся и родителям |
| Стипендии | Меры поддержки: бюджетные места, экипировка, сборы, питание, страхование |

## 1. Сведения об образовательной организации (приказ 831, обязательно)

Берём 14 подразделов `content/sveden` из orgmu-site как есть, меняется только
наполнение.

| Ключ | Подраздел | Что здесь у спортшколы |
|---|---|---|
| common | Основные сведения | Наименование, дата создания, учредитель, адреса, режим работы, контакты, адреса объектов |
| struct | Структура и органы управления | Директор, педсовет, тренерский совет, методический совет, отделения по видам спорта, положения о них |
| document | Документы | Устав, лицензия с приложением, правила приёма, порядок зачисления/перевода/отчисления, правила внутреннего распорядка обучающихся, режим занятий, положение о платных услугах, отчёт о самообследовании, предписания надзора, коллективный договор |
| education | Образование | Перечень программ по видам спорта и этапам, численность по бюджету и договорам, формы и сроки, язык, учебные планы, календарный учебный график, аннотации, методические материалы, описание программ |
| eduStandarts | Образовательные стандарты и требования | Федеральные стандарты спортивной подготовки (ФССП) по каждому виду спорта, примерные программы Минспорта |
| managers | Руководство | Директор, заместители, руководители отделений |
| employees | Педагогический состав | Тренеры-преподаватели: должность, вид спорта, образование, квалификационная категория, спортивное звание, стаж, повышение квалификации |
| objects | Материально-техническое обеспечение | Залы, бассейн, стадион, инвентарь, медкабинет, условия питания и охраны здоровья, доступ к сети, электронные ресурсы, доступная среда |
| grants | Стипендии и меры поддержки | Бюджетные места, бесплатная экипировка, участие в сборах и соревнованиях, страхование, питание на сборах, стипендии спортсменам при наличии |
| paid_edu | Платные образовательные услуги | Положение, образец договора, стоимость по программам, порядок оплаты |
| budget | Финансово-хозяйственная деятельность | План ФХД, объём средств по источникам |
| vacant | Вакантные места | Количество мест по программам, этапам и источникам финансирования |
| inter | Международное сотрудничество | Обычно «не осуществляется»; раздел всё равно присутствует |
| catering | Организация питания | Обычно на сборах или «не осуществляется» |

Сопутствующие обязательные страницы, тоже из orgmu-site: доступная среда,
противодействие коррупции, антитеррористическая защищённость, обратная
связь, политика обработки ПДн, согласие на обработку ПДн, карта сайта,
версия для слабовидящих.

Специфичное для спорта, чего в вузовском каркасе нет:
- **Антидопинг** — обязательный раздел для спортивных школ (образовательные
  антидопинговые программы, ссылки РУСАДА, ответственный).
- **Спортивные разряды и звания** — порядок присвоения, списки присвоенных.
- **Медицинское обеспечение** — углублённое медобследование, допуск врача,
  требования к справкам по этапам.

## 2. Поступающим (аналог раздела абитуриентов)

Посадочная страница по образцу `postupayushchim` + `priem.yml`:
- Приёмная кампания {год}: сроки приёма документов, индивидуального отбора,
  публикации результатов, зачисления. Треки вместо уровней вуза: по видам
  спорта или по типу программы (ДОПСП / общеразвивающая).
- Правила приёма и порядок индивидуального отбора: возраст по видам спорта,
  контрольные нормативы по этапам, документы, медицинское заключение,
  согласие на ПДн, договор.
- Бюджет и платно: как распределяются места, стоимость.
- Перевод из другой школы, зачисление на более поздний этап.
- Результаты отбора: обезличенные списки (аналог рейтинговых списков).
- Пробное занятие и форма записи (для частных секций — главная воронка).
- Приёмная комиссия: адрес, часы, телефон, ответственный, Госуслуги /
  Навигатор дополнительного образования.
- FAQ родителей.

## 3. Образовательные программы (каталог)

Аналог `programmy`: карточка программы.
- Вид спорта, тип программы, этапы и сроки по этапам, возраст зачисления,
  минимальная численность, требования к результатам, ФССП, учебный план,
  календарный график, аннотация, тренеры, объекты, группы с набором.

## 4. Структура организации и персоны

Аналог `struktura` и `persony`: отделения по видам спорта, администрация,
тренеры-преподаватели, медицинский и методический персонал. Карточка тренера
дополнительно: спортивное звание, достижения учеников, группы.

## 5. Места (спортивные объекты)

Аналог `mesta`: адрес, карта, как добраться, фото, инфраструктура, какие
программы и группы здесь занимаются, доступная среда.

## 6. Обучающимся и родителям

- Расписание учебно-тренировочных занятий (сводное, фильтры).
- Календарь соревнований и сборов (аналог `meropriyatiya`).
- Спортивные разряды, присвоение, антидопинг.
- Правила посещения, форма и экипировка, страхование.
- Объявления: отмены, замены, каникулы (аналог `announcements`).
- Меры поддержки.

## 7. Новости, достижения, галерея

Аналог `novosti` + баннеры. Достижения: отдельная лента результатов
соревнований (команда или спортсмен при согласии родителей, соревнование,
место, тренер).

## 8. Контакты и навигация

Аналог `kontakty`, `navigation/main.yml`, `footer.yml`. Главное меню:
Школа · Поступающим · Обучающимся · Программы · Тренеры · Объекты · Новости ·
Контакты. «Сведения об образовательной организации» — отдельный обязательный
пункт в шапке или футере.

## 9. Что переносится из orgmu-site без изменений

- Весь каркас `sveden` (14 подразделов, labels, vocab, overrides).
- Навигация, футер, карта сайта.
- Новости, мероприятия, баннеры, объявления.
- Персоны, структура, места, программы (меняется схема полей).
- Доступная среда, антитеррор, коррупция, обратная связь, политика ПДн.
- Платные услуги.
- Версия для слабовидящих.

- Антидопинг, разряды, медобеспечение.
- Пробное занятие и форма записи.

## 11. Решения

- Оба режима: лицензированная школа и секция без лицензии. Переключатель в
  конфиге сайта; при выключенном режиме раздел «Сведения» и приёмная
  кампания скрыты, остаются программы, тренеры, объекты, группы, цены,
  запись, документы по ПДн и оферта.
- Без многоязычности.
- Группы и расписание ведём на сайте.
- Имена спортсменов в достижениях и списках: по умолчанию обезличено
  (команда, возрастная категория), у записи есть флаг «согласие получено»,
  тогда выводится ФИО. (Предположение, не подтверждено.)

## 12. Контент-модель: поля сущностей

### Программа (`programs/*.yml`)
- id, название, вид спорта, тип: `dopsp` | `general`
- этапы: список { этап, срок в годах, возраст зачисления, нормативы }
- описание, аннотация, результат освоения
- документы: учебный план, календарный график, ФССП, рабочая программа
- финансирование: бюджет / договор / оба; тарифы (ссылки) при договоре
- тренеры (ссылки), объекты (ссылки)
- статус: набор открыт / закрыт

### Группа (`groups/*.yml`)
- id, программа, этап, учебный год
- тренер, объект
- возрастная вилка, год рождения от/до
- расписание: список { день, начало, конец, зал }
- мест всего, мест свободно, статус: `enrolling` | `running` | `waitlist` | `closed`
- финансирование, тарифы (ссылки; если пусто — наследуются от программы)
- примечание (форма, инвентарь)

### Тариф (`tariffs/*.yml`)
- id, название, тип: `subscription` | `single` | `trial` | `period` | `camp`
- цена, валюта
- объём: занятий N / календарный период (месяц, квартал, год) / безлимит
- срок действия абонемента в днях после активации
- заморозка: возможна ли, сколько дней, условия
- пропуски: сгорают / переносятся / отработка
- скидки: список { условие, размер } — второй ребёнок, многодетные, оплата
  за полгода, акция до даты
- способы оплаты: касса, онлайн, по реквизитам; возврат
- действует с / по (для смены цен с нового сезона)
- применимость: виды спорта / программы / этапы (если не задано — ко всем)

Страница «Цены» собирается из тарифов, сгруппированных по видам спорта;
на странице группы и программы выводятся только применимые.
Для лицензированной школы тарифы также отображаются в разделе «Платные
образовательные услуги» со ссылкой на положение и договор.

### Тренер (`persons/*.yml`)
- ФИО, фото, должность, вид спорта, отделение
- образование, квалификационная категория, спортивное звание, разряд
- стаж общий / по специальности, повышение квалификации
- группы (вычисляется), достижения учеников (вычисляется)
- контакты (по желанию)

### Отделение (`structure/*.yml`)
- название, вид спорта, руководитель, тренеры, положение, контакты

### Объект (`places/*.yml`)
- название, адрес, координаты, как добраться, фото
- инфраструктура: раздевалки, душ, парковка, медкабинет, доступная среда
- режим работы, контакт
- группы (вычисляется)

### Событие (`events/*.yml`)
- название, тип: соревнование / сборы / открытое занятие / каникулы / собрание
- даты, объект или внешний адрес, вид спорта, программы
- регламент (файл), результаты (файл или ссылка на достижения)

### Достижение (`achievements/*.yml`)
- событие или название соревнования, дата, вид спорта
- участник: команда / спортсмен { ФИО, согласие: bool, год рождения }
- результат: место / разряд / звание, тренер

### Новость, объявление, баннер
Как в orgmu-site.

### Приём (`priem.yml`)
- год, сроки по этапам кампании, треки по видам спорта
- документы, медицинские требования, нормативы по этапам
- приёмная комиссия: адрес, часы, телефон, ответственный
- ссылки: Госуслуги, Навигатор ДО
- форма записи на пробное: куда отправлять

### Сведения (`sveden/`)
Как в orgmu-site, 14 подразделов.

### Конфиг сайта (`site.yml`)
- название, краткое название, лицензия: bool
- виды спорта
- контакты, соцсети, мессенджеры
- Метрика, карты
- режим именования спортсменов по умолчанию

## 14. Что забыли: итоги анализа сайтов (см. `research/`)

Сверка плана с 11 российскими сайтами, 11 зарубежными и 16 платформами.

### A. Пропуски в контент-модели (критично)
1. **Сезон / учебный год** как сущность: даты, дата старта набора, статус,
   архив прошлых сезонов. Сейчас только поле «учебный год» у группы.
2. **Возраст по дате рождения** на контрольную дату, а не «7–10 лет». Для
   спортшкол в РФ зачисление тоже по году рождения. У группы: год рождения
   от/до плюс контрольная дата.
3. **Статус набора и места** у группы есть, но нет **листа ожидания** как
   действия для родителя: кнопка «в лист ожидания», правила.
4. **Уровни / аттестации**: пояса, разряды, «уровни обучения» с критериями
   перехода и датами аттестаций. У нас этапы ДОПСП, но для единоборств,
   гимнастики, плавания нужна своя шкала (ступени, пояса, звери).
5. **Pathway**: схема пути ученика от набора до спортивной группы и сборной.
   Выводится из этапов и уровней как страница-диаграмма.
6. **Событийный слой** шире: лагеря, сборы, интенсивы, каникулярные
   программы, аттестации, открытые уроки, отчётные выступления, дни
   открытых дверей, «просмотры в группы» с датами. Тип события расширить.
7. **Правила пропусков и отработок** есть у тарифа, но нет **заявить пропуск
   заранее** и **записаться на отработку**: это функции ЛК, фиксируем как
   отложенные.
8. **Семья**: несколько детей, несколько опекунов, скидка за второго. На
   сайте без ЛК выражается только в тарифах и форме записи (поле «ещё
   дети»).
9. **Документы ученика со сроками**: медсправка, страховка, согласие на
   фото. На сайте: требования и шаблоны по этапам в «Поступлении»; контроль
   сроков — функция ЛК (отложено).

### B. Пропущенные разделы (добавить в карту страниц)
10. **Защита детей / безопасная среда** (safeguarding): ответственное лицо с
    контактами, кодексы поведения для тренеров, родителей, учеников,
    политика «привёл-забрал», правила переписки тренера с ребёнком, план
    действий при буллинге, согласие на фото. В РФ частично закрывается
    антитеррором и охраной труда, но раздел «Родителям о безопасности»
    выделить отдельно.
11. **Кодексы поведения** как документы, на которые ссылается форма записи.
12. **Страхование** спортсмена: как оформить, кто страхует, документы.
13. **Волонтёры и судьи**: роли, как стать судьёй, обучение. Для
    муниципальной школы и федерации важно.
14. **Спонсоры и партнёры**, страница поддержки: донаты, фонд, субсидии,
    ПФДО-сертификат, Пушкинская карта.
15. **Магазин / экипировка**: минимум страница «что купить и где», с
    требованиями по форме на каждом направлении.
16. **Дни рождения и аренда залов**, B2B: школы и сады, корпоративные
    клиенты. Для частных секций источник дохода, для муниципальных «услуги
    юрлицам».
17. **Алумни / Hall of Fame / «Наши чемпионы»**: кто из выпускников где,
    счётчики на главной (спортсменов, в сборных, разрядов за год).
18. **Справочники для родителей**: как выбрать вид спорта, когда начинать,
    медсправки, как получить разряд, ГТО, питание, коды дисквалификации,
    нормативы. Это «Инструкции» или блог.
19. **FAQ с правилами**: лист ожидания, уведомление об отчислении за 30
    дней, присутствие родителей, форма, пропуски.
20. **Вакансии / карьера тренера**.
21. **Онлайн-трансляции** соревнований и видеоархив.
22. **Accessibility statement** нет ни у кого за рубежом; у нас версия для
    слабовидящих обязательна. Оставляем.
23. **Электронная приёмная / обращения граждан** и **анкетирование (НОКО)**
    для лицензированного режима.

### C. Функции и UX
26. **Подбор группы**: фильтр по возрасту ребёнка, виду спорта, району,

28. **Интерактивная карта объектов** с фильтрами.

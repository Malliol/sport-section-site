# Типовой сайт спортивной секции (образовательная организация)

Статус: черновик, обсуждается.

## 1. Кто пользователи сайта

- Родители (главная аудитория): ищут секцию для ребёнка, сравнивают, записываются.
- Взрослые ученики (если секция принимает взрослых).
- Действующие ученики и их родители: расписание, новости, оплата, документы.
- Проверяющие органы / партнёры: лицензия, уставные документы, реквизиты.

## 2. Сущности (контент-модель)

- **Направление / курс** — вид спорта или программа: описание, возраст, уровень
  (начинающие / продолжающие / спортивная группа), длительность, стоимость,
  расписание, тренер(ы), место, что нужно для занятий (форма, инвентарь),
  фото/видео, результаты обучения.
- **Педагог / тренер** — фото, биография, образование, звания и разряды,
  стаж, какие курсы ведёт, достижения учеников.
- **Площадка / место проведения** — адрес, карта, как добраться, фото,
  инфраструктура (раздевалки, душ, парковка), какие курсы здесь проходят.
- **Группа** — конкретный поток: курс + педагог + площадка + расписание +
  возрастная вилка + наличие мест.
- **Условия поступления** — возраст, медсправка, пробное занятие, документы,
  договор, порядок зачисления, противопоказания.
- **Цены и оплата** — абонементы, разовые занятия, скидки (многодетные,
  второй ребёнок), способы оплаты, возвраты и пропуски.
- **Документы** — лицензия на образовательную деятельность, устав, правила
  посещения, договор-оферта, политика ПДн, согласие на обработку.
- **Новости / события** — соревнования, сборы, каникулы, набор.
- **Достижения** — медали, разряды, результаты команд.
- **Галерея** — фото и видео с занятий и соревнований.
- **FAQ** — типовые вопросы родителей.
- **Отзывы**.
- **Контакты** — телефоны, мессенджеры, соцсети, режим работы, реквизиты.

## 3. Карта страниц

- Главная: УТП, направления, ближайший набор, тренеры, площадки, CTA «записаться».
- Направления (список) → страница курса.
- Тренеры (список) → страница тренера.
- Площадки (список) → страница площадки с картой.
- Расписание (сводное, фильтр по курсу / площадке / возрасту).
- Поступление: условия, шаги, форма записи на пробное.
- Цены.
- О секции: история, миссия, лицензия, команда.
- Новости → статья.
- Достижения.
- Галерея.
- FAQ.
- Документы.
- Контакты.
- Служебные: политика конфиденциальности, согласие на ПДн, 404.

## 4. Функции

- Форма «записаться на пробное» (имя, телефон, возраст ребёнка, курс, площадка).
  Отправка в Telegram / почту, согласие на ПДн обязательно.
- Фильтр расписания и направлений.
- Карта площадок (Яндекс.Карты).
- Кнопки связи: телефон, WhatsApp, Telegram.
- SEO: мета, OpenGraph, sitemap, robots, микроразметка Organization /
  Course / Person / Place / Event.
- Аналитика: Яндекс.Метрика.
- Адаптив и доступность.

# Типовой сайт спортивной школы / секции

Версия 2. Структура согласована, стек не выбран.

Основа: сайт образовательной организации (`orgmu-site`), спроецированный на
спортивную школу. Спортивные школы с 01.01.2023 — организации
дополнительного образования, на них распространяются ФЗ-273 ст. 29 и приказ
Рособрнадзора № 831 о структуре сайта. Исследование аналогов в `research/`.

## 1. Решения

- Два режима: **лицензированная организация** и **секция без лицензии**.
  Флаг `license` в конфиге. Без лицензии скрыты «Сведения», приёмная
  кампания, электронная приёмная, НОКО, ПФДО.
- Без многоязычности.
- Группы, расписание, сезоны ведём на сайте.
- Имена спортсменов публикуются только при согласии опекуна, флаг у ученика.
  По умолчанию обезличено.
- Личный кабинет проектируем сразу (раздел 7), реализуем после сайта.
- Три корзины функций: **ядро** всегда, **опция** включается флагом,
  **ЛК** живёт в кабинете, на сайте только ссылка.

## 3. Карта страниц

Пометки: **Я** ядро, **О** опция (флаг в конфиге), **Л** лицензированный режим.

### Главная (Я)
УТП, подбор группы (возраст ребёнка, вид спорта, район, день), направления,
ближайший набор и события, счётчики (спортсменов, в сборных, разрядов за
год), тренеры, объекты, отзывы, новости, CTA «пробное занятие».

### Направления и программы (Я)
- `/napravleniya` список видов спорта → `/napravleniya/{sport}`: описание,
  для кого, с какого возраста, что даёт, этапы и уровни, pathway-схема,
  тренеры, объекты, группы с набором, тарифы, экипировка «что нужно»,
  FAQ по виду спорта, достижения.
- `/programmy/{id}` карточка программы (Л обязательно, иначе часть
  страницы направления): этапы, сроки, возраст, нормативы, ФССП, учебный
  план, график, аннотация.
- `/napravleniya/{sport}/{place}` вид спорта × объект для SEO (О).

### Группы и расписание (Я)
- `/raspisanie` сводное с фильтрами: вид спорта, объект, возраст, день,
  тренер, статус набора. Вид: таблица по дням / список групп.
- `/gruppy/{id}` карточка группы: программа, этап, уровень, сезон, тренер,
  объект и зал, расписание, год рождения от/до, мест свободно, статус,
  тарифы, кнопка «записаться / в лист ожидания».
- Отмены и замены занятий выводятся на карточке и в сводном расписании.

### Тренеры (Я)
`/trenery` список с фильтром по виду спорта → `/trenery/{id}`: фото,
должность, образование, категория, звание, стаж, повышение квалификации,
группы, достижения учеников, отзывы.

### Объекты (Я)
`/obekty` список + интерактивная карта с фильтрами (при объектах > 1) →
`/obekty/{id}` мини-лендинг: адрес, карта, проезд, фото, инфраструктура,
доступная среда, режим, группы с возрастом, временем, статусом и ценой,
кнопка «резерв места».

### Поступающим (Я, расширяется в Л)
- `/postupayushchim` посадочная: шаги «выбрать направление → подобрать
  группу → пробное → документы → договор → оплата», ближайшие просмотры в
  группы и дни открытых дверей, форма записи.
- `/postupayushchim/usloviya` возраст по видам спорта, медицинские
  требования по этапам, документы, шаблоны заявлений и согласий.
- `/postupayushchim/priem` (Л) приёмная кампания {год}: сроки, индивидуальный
  отбор, нормативы, бюджет / договор, результаты отбора обезличенно,
  приёмная комиссия, Госуслуги, Навигатор ДО.
- `/postupayushchim/perevod` перевод из другой школы, зачисление на поздний
  этап.
- `/postupayushchim/otchislenie` сценарий «выйти»: заявление, сроки
  уведомления, возвраты.
- `/faq`.

### Цены (Я)
`/ceny` тарифы по видам спорта: абонементы, разовые, пробное, периоды,
сборы; скидки; способы оплаты; заморозка, пропуски, возврат; гарантия

### Школа (Я)

## 4. Контент-модель

Файлы контента в `content/`, формат YAML/JSON/Markdown.

### `site.yml` конфиг
- название, краткое, лицензия: bool, виды спорта
- контакты, адреса, соцсети, мессенджеры, реквизиты
- флаги: `adults`, `levels`, `support`, `services`, `volunteers`,
  `distance`, `streams`, `sponsors`, `seo_sport_place`
- словарь терминов (раздел 2)
- именование спортсменов по умолчанию: `anonymous | named_with_consent`
- форма записи: куда отправлять, поля, UTM
- Метрика, карты, ЛК: `none | external_url | builtin`

### Сезон `seasons/*.yml`
- id, название, дата начала, дата окончания
- дата старта набора, дата окончания набора
- контрольная дата возраста (например 1 января сезона)
- статус: `upcoming | enrolling | running | archived`

### Направление `sports/*.yml`
- id, название, описание, для кого, с какого возраста
- этапы (ссылки на программы), уровни (если `levels`)
- экипировка «что нужно», FAQ, противопоказания, медтребования
- фото, тренеры, объекты (вычисляется из групп)

### Уровень `levels/*.yml` (опция)
- направление, порядок, название (пояс, ступень), возраст
- критерии перехода: навыки, нормативы, посещаемость
- аттестация: формат, периодичность

### Программа `programs/*.yml`
- id, название, направление, тип: `dopsp | general`
- этапы: { этап, срок лет, возраст зачисления, нормативы, мин. численность }
- описание, аннотация, результат освоения
- документы: учебный план, календарный график, ФССП, рабочая программа
- финансирование: `budget | paid | both`, тарифы
- статус набора

### Группа `groups/*.yml`
- id, программа, этап, уровень, сезон
- тренер, замещающие тренеры, объект, зал
- год рождения от/до (на контрольную дату сезона), пол: `any | m | f`
- расписание: [{ день, начало, конец, зал }]
- мест всего, мест свободно, лист ожидания: макс, статус:
  `enrolling | running | waitlist | closed`
- финансирование, тарифы (наследуются от программы)
- флаги: пробное разрешено, разовое разрешено
- примечание
- отмены/замены: [{ дата, тип: `cancel | move | substitute`, детали }]

### Тариф `tariffs/*.yml`
- id, название, тип: `subscription | single | trial | period | camp | fee`
- цена, объём (N занятий / период / безлимит), срок действия
- заморозка, пропуски: `burn | transfer | makeup`, правила отработки
- скидки: [{ условие, размер }], рассрочка
- гарантия: возврат pro-rata при уходе в первый период (опционально)
- способы оплаты, возврат
- действует с / по; применимость: виды спорта, программы, этапы, группы

### Тренер `persons/*.yml`
- ФИО, фото, должность, роли (тренер, руководитель отделения, админ)
- вид спорта, отделение, образование, категория, звание, разряд
- стаж, повышение квалификации, контакты
- группы, достижения учеников (вычисляются)

### Отделение `structure/*.yml`
- название, вид спорта, руководитель, тренеры, положение, контакты

### Объект `places/*.yml`
- название, адрес, координаты, проезд, фото
- залы: [{ id, название, вместимость }]
- инфраструктура, доступная среда, режим, контакт

### Событие `events/*.yml`
- название, тип: `competition | camp | intensive | exam | open_lesson |
  showcase | open_day | tryout | holidays | meeting`
- даты, объект или внешний адрес, виды спорта, программы, группы
- регистрация: нужна ли, сроки, стоимость (тариф), мест
- регламент, результаты, трансляция
- промо: early-bird до даты, скидка второму ребёнку

### Достижение `achievements/*.yml`
- событие или название, дата, вид спорта
- участник: команда / спортсмен { ФИО, согласие, год рождения }
- результат, тренер

### Ученик-алумни `alumni/*.yml`
- ФИО (с согласием), годы в школе, вид спорта, тренер, где сейчас

### Документ `documents/*.yml`
- название, тип: `charter | license | rules | contract | consent |
  code_of_conduct | policy | report | form`
- файл, дата, версия, для каких ролей/форм обязателен, режим: `Л | all`

### Безопасность `safety.yml`
- ответственное лицо, контакты
- кодексы (ссылки на документы), политика «привёл-забрал»
- действия при буллинге, правила общения, согласие на фото

### Приём `priem.yml` (Л)
- год, сроки по этапам, треки, нормативы, документы, комиссия, ссылки

### Новости, объявления, баннеры, отзывы, статьи, вакансии, FAQ
Как в `orgmu-site`, FAQ с категориями (общее, вид спорта, оплата, правила).

### Сведения `sveden/` (Л)
Как в `orgmu-site`.

### Заявка (не контент, идёт в CRM / Telegram / почту)
- тип: `trial | enroll | waitlist | event | callback | question`
- ребёнок: имя, год рождения; опекун: имя, телефон, почта
- направление, группа, объект, событие
- ещё дети: bool
- источник: UTM, страница входа, реферер
- согласие на ПДн: bool, дата, версия документа

## 5. Функции сайта

Ядро:
- Подбор группы: возраст ребёнка → виды спорта → район → день → группы.
- Сводное расписание с фильтрами, отмены и замены.
- Карточка группы со статусом, местами, листом ожидания.
- Форма заявки с источником, согласие обязательно, отправка в выбранный
  канал.
- Интерактивная карта объектов.
- Pathway-схема из этапов и уровней.
- Счётчики на главной.
- Фильтр достижений с учётом согласий.
- Календарь событий с регистрацией и экспортом в календарь.
- SEO: мета, OpenGraph, sitemap, микроразметка Organization, SportsClub,
  Course, Person, Place, Event, Offer.
- Версия для слабовидящих, адаптив.
- Метрика.

Опции по флагам: SEO-страницы вид × объект, трансляции, дни рождения и
аренда, волонтёры, поддержка и ПФДО, дистанционно, взрослые.

## 6. Что не делаем на сайте
Магазин (только ссылка и список «что купить»), онлайн-оплата вне ЛК,
многоязычность, собственный чат.

## 7. Личный кабинет

### Принципы
- **Один аккаунт = один человек.** Вход по телефону или почте, одна учётная
  запись на всю жизнь в школе. Роли навешиваются на аккаунт и снимаются,
  аккаунт остаётся.
- **Роль = набор прав + привязка к объектам.** Тренер привязан к группам,
  родитель к детям, руководитель отделения к отделению. Права без привязки
  ничего не дают.
- **Роли совмещаются свободно.** Один человек может быть тренером, родителем
  своего ученика, судьёй и администратором. Интерфейс один, разделы кабинета
  появляются по ролям, переключатель контекста «я как тренер / я как
  родитель» там, где одно действие трактуется по-разному.
- **Ребёнок не является аккаунтом до 14 лет.** Ученик — сущность, к которой
  привязаны опекуны. С 14 лет ученик может получить собственный аккаунт с
  ролью «Спортсмен», опекуны сохраняют доступ до 18.
- **Несколько опекунов на ребёнка**, с разными правами: кто платит, кто
  получает уведомления, кто может забирать (список доверенных лиц).

### Роли

| Роль | Привязка | Кто назначает |
|---|---|---|
| Гость | нет | сам, при регистрации |
| Родитель / опекун | ученики | сам при записи, подтверждает администратор |
| Спортсмен | свой профиль ученика | администратор, с 14 лет |
| Тренер-преподаватель | группы | администратор |
| Руководитель отделения | отделение (все его группы и тренеры) | администратор |
| Администратор / методист | филиал или вся школа | владелец |
| Медработник | все ученики, только медблок | администратор |
| Судья / волонтёр | события | администратор |
| Бухгалтер / кассир | платежи | владелец |
| Владелец / директор | всё, включая настройки и роли | первый аккаунт |

### Что видит и делает каждая роль

**Гость** (зарегистрировался, детей ещё нет)
- Заявки на пробное и их статусы, лист ожидания.
- Добавить ребёнка → становится родителем после подтверждения.

**Родитель**
- Дети: карточки, документы и сроки (медсправка, страховка, согласия),
  загрузка сканов, напоминания об истечении.
- Расписание всех детей в одном календаре, уведомления об отменах и
  заменах, экспорт в календарь телефона.
- Посещаемость, заявить пропуск заранее, записаться на отработку по
  правилам тарифа.
- Абонементы: остаток, срок, продление, заморозка, история платежей,
  задолженность, оплата онлайн, чеки.
- Прогресс: уровень, аттестации, нормативы, отметки тренера, сертификаты.
- События: записать ребёнка на соревнование, сборы, лагерь; RSVP;
  документы на выезд.
- Чат с тренером группы и администратором; рассылки.
- Доверенные лица, кто может забирать.
- Заявления: перевод в другую группу, отчисление, справка.
- Второй опекун: пригласить, настроить права.

**Спортсмен** (14+)
- Своё расписание, посещаемость, прогресс, нормативы, разряды.
- RSVP на события, чат с тренером.
- Без финансов и документов, если опекун не передал.

**Тренер**
- Мои группы: состав, контакты опекунов, медицинские отметки и допуски.
- Журнал: отметить посещаемость с телефона, причины, замена/отмена
  занятия с уведомлением родителям.
- Прогресс: выставить уровень, результаты нормативов, комментарий, запрос
  на аттестацию, рекомендация к переводу на следующий этап.
- Заявки в мои группы: принять, отклонить, предложить другую группу.
- Лист ожидания моих групп, пригласить следующего.
- События: заявить спортсменов на соревнование, внести результаты.
- Чат с родителями группы, объявления группе.
- Мои занятия и часы для расчёта зарплаты, график, запрос замены.

**Руководитель отделения**
- Всё, что тренер, по всем группам отделения.
- Назначение тренеров на группы, замены.
- Открытие набора, лимиты мест, расписание отделения, занятость залов.
- Отчёты: наполняемость, посещаемость, отток, результаты.

**Администратор**
- Заявки и лиды: воронка, источники, статусы, назначение на группу.
- Ученики, опекуны, подтверждение связи родитель-ребёнок.
- Группы, сезоны, расписание, залы, события.
- Тарифы, скидки, выставление счетов, возвраты, заморозки.
- Документы: шаблоны договоров и согласий, отправка на подпись, статусы.
- Рассылки по сегментам: группа, отделение, должники, не ответившие.
- Контент сайта: новости, достижения, галерея, страницы.
- Отчёты школы.

**Медработник**
- Медсправки и допуски по всем ученикам, сроки, групп здоровья.
- Отметка «допущен / не допущен», видна тренеру.
- Журнал травм.

**Судья / волонтёр**
- События, где назначен; протоколы и результаты; свои часы.

**Бухгалтер**
- Платежи, счета, долги, выгрузка в 1С, акты, отчёты. Без доступа к
  медданным и чатам.

**Владелец**
- Настройки школы, режим «с лицензией», роли и приглашения, интеграции,
  биллинг платформы.

### Совмещение: типовые случаи
- **Тренер + родитель.** В разделе «Мои дети» видит ребёнка как родитель,
  в «Мои группы» как тренер. Если ребёнок в его же группе, в журнале он
  отмечает его как любого другого; оплату видит только во вкладке родителя.
- **Администратор + тренер.** Кабинет администратора шире, вкладка
  «Мои группы» остаётся для быстрого доступа и журнала с телефона.
- **Руководитель отделения + тренер** стандартная ситуация, права
  складываются.
- **Спортсмен 16 лет + волонтёр-судья** на детских соревнованиях.
- **Родитель двух детей в разных отделениях** один кабинет, календарь
  общий, финансы по семье.
- **Два опекуна** оба видят ребёнка, права настраиваются: платит один,
  уведомления обоим, забирать может третье лицо из списка.

### Правила доступа к данным
- Персональные данные ученика видят: опекуны, тренер его группы,
  руководитель его отделения, администратор, медработник (медблок),
  владелец. Другие тренеры не видят.
- Медданные видят медработник, опекуны, тренер только допуск и
  ограничения, без диагноза.
- Финансы видят опекуны с правом «платит», администратор, бухгалтер.
- Чаты: родитель видит только чаты своих групп; тренер только своих.
- Публикация имени и фото ученика на сайте только при согласии опекуна,
  флаг хранится у ученика и проверяется при выводе достижений и галереи.
- Журнал действий по чувствительным данным.

### Что из ЛК попадает на сайт
- Из ЛК на сайт уходят: статус набора и свободные места групп, расписание
  и отмены, достижения с учётом согласий, события.
- С сайта в ЛК уходят: заявки с источником, запись в лист ожидания,
  регистрация на событие.

### Очерёдность
1. Гость, Родитель, Администратор: заявки, дети, документы, расписание,
   абонементы, оплата.
2. Тренер: журнал, прогресс, чат.
3. Руководитель отделения, Медработник, Бухгалтер.
4. Спортсмен, Судья, двойные опекуны с разграничением прав.

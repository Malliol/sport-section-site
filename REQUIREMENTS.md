# Требования: типовой сайт и кабинет спортивной школы

Версия 0.1, 7 октября 2026. Черновик, дополняется по разделам.

Как читать:
- **Истории** `US-<роль>-<n>`: кто и зачем. Формат «Как <роль>, я хочу <действие>, чтобы <результат>».
- **Требования** `<КОД>-<n>`: что система должна делать. У каждого приоритет, режим, критерий приёмки, ссылка на истории.
- Приоритет: **Я** ядро первой версии, **О** опция по флагу, **Б** будущее.
- Режим: **все**, **Л** только с лицензией, **БЛ** только без лицензии.
- Термины по словарю PLAN.md, раздел 2. Связи сущностей в PLAN.md, раздел 4a.
